## 🚀 التشغيل المحلي (على جهاز الكمبيوتر)
بكل بساطة وبنقرة واحدة:
1. انقر نقراً مزدوجاً على ملف **`تشغيل_النظام.bat`** في المجلد الرئيسي للمشروع.
2. سيفتح المتصفح مباشرة على: **`http://localhost:5000`**.

## 🌐 خطوات الرفع والنشر على استضافة رندر (Render)

تم تجهيز المشروع بالكامل للنشر بنقرة واحدة عبر خطة **Render Free Tier**:

### الخطوة 1: رفع المشروع إلى GitHub
1. افتح حسابك في GitHub وأنشئ مستودعاً جديداً (New Repository)، مثلاً باسم: `tahfeez-system`.
2. في مجلد المشروع على جهازك، افتح Terminal ونفذ الأوامر:
```bash
git init
git add .
git commit -m "Initial commit - Saba Relief Tahfeez System"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/tahfeez-system.git
git push -u origin main
```

### الخطوة 2: إنشاء خدمة الويب على Render
1. سجّل دخولك إلى موقع [Render](https://render.com).
2. اضغط على زر **New +** ثم اختر **Web Service**.
3. اربط مستودع GitHub الخاص بالمشروع (`tahfeez-system`).
4. اضبط الإعدادات التالية:
   - **Name:** `tahfeez-system` (أو أي اسم تفضله)
   - **Language:** `Node`
   - **Region:** `Frankfurt (EU Central)` أو أي منطقة قريبة.
   - **Branch:** `main`
   - **Build Command:** `npm run build`
   - **Start Command:** `npm start`
   - **Plan Type:** `Free`

### الخطوة 3: إضافة متغيرات البيئة (Environment Variables)
في قسم **Environment Variables** في صفحة الإعداد على Render، أضف المتغيرات التالية:
1. `NODE_ENV` = `production`
2. `PORT` = `5000`
3. `MONGO_URI` = رابط اتصال قاعدة بيانات MongoDB الخاص بك
4. `JWT_SECRET` = مفتاح أمان عشوائي لتشفير التوكن (مثال: `tahfeez_super_secret_jwt_key_2026`)
5. `GEMINI_API_KEY` = مفتاح Gemini API الخاص بك (اختياري لتحليلات الذكاء الاصطناعي)

### الخطوة 4: النشر (Deploy)
* اضغط على **Create Web Service**.
* سيقوم Render تلقائياً بتثبيت الحزم، وبناء واجهة React في ثوانٍ، وتشغيل السيرفر.
* ستحصل على رابط مباشر عام (مثل: `https://tahfeez-system.onrender.com`) يعمل 24/7 عبر الإنترنت على الكمبيوتر والجوال.
